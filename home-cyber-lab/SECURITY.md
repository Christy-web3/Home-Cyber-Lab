# Security policy

## Educational scope

This repository documents an isolated lab owned and controlled by the author. Commands and testing procedures must only be used on systems where explicit authorisation has been granted.

## Sensitive information

Do not commit:

- Passwords, API keys, tokens, cookies, or session data
- Private keys or certificates
- Public IP addresses tied to an individual
- University or employer internal hostnames and addresses
- Raw packet captures or logs containing unrelated personal data
- Virtual machine images

Private RFC 1918 addresses shown in the documentation belong only to the isolated lab design.

## Reporting an issue

If a future version of this repository accidentally exposes sensitive information, remove the public content, rotate any affected credential, and purge the secret from Git history before republishing.
